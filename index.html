Bibliotecas API Framework
Conjunto de código que contiene funciones, clases y métodos listos para ser utilizados en un programa. Proporciona un conjunto de funcionalidades específicas que se pueden reutilizar en diferentes proyectos, permitiendo la reutilización de código, aumentando la productividad de los desarrolladores y fomentando la modularidad y escalabilidad del proyecto. Una Interfaz de Programación de Aplicaciones (Application Programming Interface) es un conjunto de reglas y protocolos que permiten que diferentes programas se comuniquen e interactúen entre sí. Posibilita el acceso e interacción con servicios o funcionalidades proporcionadas por un sistema o aplicación, y están diseñadas para facilitar la integración y la comunicación entre diferentes componentes de software. Conjunto de herramientas, bibliotecas y convenciones que proporcionan una estructura para facilitar el desarrollo de software. Agilizan el proceso de creación de una aplicación al proporcionar estructuras, reglas y patrones, diferenciandose de una biblioteca al brindarnos funcionalidades listas para usar, pero también impone una arquitectura y flujo de trabajo específico para el desarollo de aplicaciones.

Modelo de inteligencia artificial a utilizar

Para desarrollar (tanto este proyecto como en general) utilizo ChatGPT, un modelo de lenguaje desarrollado por OpenAI. Está basado en la arquitectura GPT (Generative Pre-trained Transformer) y es capaz de comprender y generar texto de manera coherente y contextualmente relevante. ChatGPT se entrena con una amplia variedad de datos textuales, lo que le permite responder preguntas, generar texto creativo, proporcionar explicaciones y realizar tareas relacionadas con el lenguaje natural.

Para utilizarlo, se puede acceder a través de la API de OpenAI, lo que permite integrar sus capacidades en aplicaciones y servicios personalizados. Alternativamente, también se puede utilizar a través de la interfaz web de OpenAI, lo que facilita su uso para tareas de generación de texto, asistencia en la redacción y otras aplicaciones relacionadas con el procesamiento del lenguaje natural.
